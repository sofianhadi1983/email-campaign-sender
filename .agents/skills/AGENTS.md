# Codex Skills

## Purpose

- Define reusable Codex workflows for generating and executing PRPs.

## Ownership

- `generate-prp/` owns PRP research and generation instructions.
- `execute-prp/` owns PRP implementation and validation instructions.

## Local Contracts

- Every skill must contain a valid `SKILL.md` with matching folder and frontmatter names.
- PRP generation must use the repository template under `PRPs/templates/`.

## Work Guidance

- Keep workflow steps explicit, concise, and executable.

## Verification

- Run the Codex skill validator for every changed skill.
